# spike-html-hosting-sdk

The site SDK and template of spike-html-hosting, published as `@jaimestill/spike-html-hosting-sdk`.
It is planned to hold what the spike's three GitHub Pages sites consume by tag: the package they
build with, the template they start from, and the bins they run.

It holds none of them yet. package.json's version stays `0.0.0`, which the release workflow never
tags, until the first release, v0.1.0.

- `mise run install`: install the pinned tools and node_modules.
- `mise run check`: the check.
- `mise run currency`: report every pin behind its latest.
